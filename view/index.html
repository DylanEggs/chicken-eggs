  2. Tap the Share button ⬆️.
  3. Choose Add to Home Screen.
  4. Tap Add.

  1. Open this page in Chrome.
  2. Tap the ⋮ menu.
  3. Choose Add to Home screen or Install app.
  4. Confirm Add / Install.
